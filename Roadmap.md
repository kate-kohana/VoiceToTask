# Roadmap (План работ на семестр)

## Lab 1
- Разработать план проекта на семестр
- Определить требования к голосовому помощнику
- Провести анализ существующих решений (Whisper, Qwen, аналоги)

## Lab 2
- Изучить библиотеки для распознавания речи (Whisper, Vosk)
- Изучить LLM для анализа и структурирования задач (Qwen, Llama, GPT4All)
- Определиться с выбором языка программирования (Python) и инструментов разработки
- Исследовать форматы хранения задач (JSON, Markdown, интеграция с Todoist/Trello)

## Lab 3
- Начало разработки архитектуры приложения
  - Модуль записи аудио с микрофона
  - Модуль распознавания речи (Whisper)
  - Модуль анализа текста через LLM
- Базовая реализация CLI-интерфейса оператора
- Тестирование связки "запись → транскрипция"

## Lab 4
- Интеграция LLM (Qwen 2.5) для извлечения задач из текста
- Реализация парсера задач (приоритеты, сроки, категории)
- Сохранение результатов в JSON-файлы
- Обработка аудиофайлов (загрузка и распознавание)

## Lab 5
- Улучшение качества распознавания (шумоподавление, работа с акцентами)
- Добавление режима реального времени (потоковое распознавание)
- Реализация экспорта задач в Markdown и текстовые файлы
- Функции мониторинга: логирование ошибок, статистика использования

## Lab 6
- Оформление результатов
  - Подготовка документации (инструкция по запуску, описание API модулей)
  - Создание презентации и демо-видео
  - Тестирование на разных устройствах и ОС
- Финальная сборка проекта
